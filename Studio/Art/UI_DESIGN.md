# Interface design: Camera Body

> Status: **Current** (evening of 11/15, redesigned by Claude following the producer's “the UI looks awful; redo it creatively”). Previous version moved to archive/UI_DESIGN_1114.md (`archive/UI_DESIGN_1114.md`; project reference, not included).
> Build script: `Tools/ue_scripts/ui_camera_body.py` (clears and rebuilds the HUD / hints / editing-desk buttons / pause-menu widget Blueprints, preserving every C++ binding name). Textures: `Tools/gen_camera_body_ui.py` → `import_camera_body_ui.py`; stamina-ring material: `ui_stamina_ring.py`.

## 1. Concept

**The whole HUD is the camera in the director's hands, plus the paper and boards on set.** No generic rounded game-UI panels: every element corresponds to a real film-set object.

| Film-set object | In the game |
|---|---|
| Slate | Scene name at top left. **Every time a new scene is entered, its clapper snaps shut once** |
| Camera tally light | Top-right status: gray STANDBY, red REC (blinking), green ROLLING, amber EDITING / REWINDING, ice-blue SLOW-MO |
| Film reels | Top-right REELS: one reel per slot; reels containing a Take are solid, and the recording reel rotates |
| Track lights | Top-right TRACKS: V1 / V2 / V3 lights; tracks with clips glow in their double's color |
| Viewfinder lines | Thin L-shaped corners; red when recording, green during playback. Camera readout at bottom right (24 FPS · 180° · ISO 800 · T2.8 · 5600K) |
| Timecode | Top `● REC 00:00:01:17` while recording (hours:minutes:seconds:frames, 30 fps), with a perforated film strip exposing left to right underneath |
| Director's note | Action-result notification: taped paper, typewriter text, red stamp at top left (TAKE / CHECKPOINT / ACTION! / NO FILM / POWER / NOTE), landing slightly tilted |
| Screenplay | Director dialogue in screenplay format: centered `DIRECTOR (V.O.)` + dialogue; tutorial captions are `( STAGE DIRECTION )`. After typing completes, wait 7 seconds then fade |
| Keycaps | Actual keycaps + verbs along the bottom, showing only usable keys |
| Film | Each editing track is perforated film, with frame divisions every 0.5 seconds; use editor-style V1 / V2 / V3 track names |
| Calling “CUT!” | Death while not recording: slate + large `CUT!` + cause of death; return to checkpoint after 1.8 seconds |
| N.G. (No Good) | Death while recording: red `N.G.` + cause + `[Q] rewind it` countdown |
| Back to one | Full-screen rewind: amber scanlines + ◀◀ + `BACK TO ONE` (set terminology: return to the first position and start again) |
| Take five | Pause title `TAKE FIVE.` (set terminology: take a five-minute break); a CALL SHEET on the right lists all keys |
| Wrap | Completion: `THAT'S A WRAP.` |

Stamina uses the same language: **a 10-segment film ring around the crosshair**, 0.5 seconds per segment. Segments darken while sprinting; when empty it flashes red, and it fades after refilling. Invisible when not sprinting.

## 5. Motion (all driven by C++, no UMG animations)

- Clapper: on a new scene, opens to -24° over 0.22 seconds, closes in 0.08 seconds, then rebounds slightly; slate simultaneously scales up 3.5%.
- Note: drops 18 px from above with a 0.4° tilt; fades after 3.2 seconds.
- REC blinks once per second; the recording reel rotates; timecode flashes red for the last 1.5 seconds.
- Stamina ring appears quickly (about 0.1 seconds), disappears slowly (about 0.3 seconds).

## 6. Main menu, pause, settings and editing-desk hints (Slate, built in C++)

These four parts do not use widget Blueprints. They are written in Slate in `Editing/UI/MenuWidgets.*`, with motion driven by `Tick`; layout uses 1080-high design units and scales uniformly with the viewport. Texture sources: `SourceAssets/UI/menu/`; import and map creation: `Tools/ue_scripts/setup_main_menu.py`.

- **Main menu** (map `L_MainMenu`, `AMainMenuGameMode` / `AMainMenuController`): background uses in-game screenshots from the three stages, each held for 8 seconds with a slow push-in and crossfade. Darkened left side for text, two oppositely scrolling film-perforation strips at top and bottom, `REC` timecode at top right. Title `CUT TO:` (amber blinking colon); five items: `START` (stage select) / `SETTINGS` / `ABOUT THE GAME` / `A NOTE FROM THE DEVELOPER` (statement, tilted paper + red `DISCLAIMER` stamp) / `QUIT`. Items slide in sequentially; hovering shifts them right, turns them amber and adds a vertical marker.
- **Stage select**: three cards (screenshot + `LEVEL n` + stage name + one sentence), with a `TUTORIAL` tag on Stage 01. Hover enlarges/brightens the card and makes its border amber. Clicking fades to black, shows `ROLL CAMERA...`, then opens the map. No save progression; all three stages are directly accessible.
- **Settings** (shared `SOptionsPanel` for main and pause menus; changes apply and save immediately): `DISPLAY` (window mode / resolution / VSync / frame cap), `GRAPHICS` (quality presets, shadows, GI, textures, effects; DLSS upscaling mode, frame generation, Reflex), `GAMEPLAY` (mouse sensitivity, invert Y, editing-desk hints; others pending), `AUDIO` (master and music volume).
- **Pause** (`P`, also `Esc` in a packaged build): `TAKE FIVE.` + current scene name; five items `RESUME` / `BACK TO LAST CHECKPOINT` / `SETTINGS` / `MAIN MENU` / `QUIT GAME`; CALL SHEET key list remains on the right. Old `WBP_PauseMenu` is no longer used.
- **Editing-desk hints**: opening the desk with `TAB` slides a small card out at top left (under the slate), with six “keycap + sentence” lines: drag a Take onto a track, drag a clip, right-click menu, click ruler to preview, `G` to roll, `TAB` back to set. `HIDE X` at top right collapses it into a `? HOW TO EDIT` button; the state is remembered (also toggled in settings).
- **Bottom keycap row**: basic keys (move / sprint / jump / crouch / use / pause) remain throughout; acquiring the camera adds `R` `TAB` `G` `Q` at the front.
